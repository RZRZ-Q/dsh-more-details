## 自行测试

使用不含敏感内容的会话即可。安装后完整退出再重开 DSH，以加载 Host 新接口。

1. **新建**：点击侧栏“新建 Chat”，确认出现右下角官网小窗；首次登录后等到“已记住网页登录”。输入一个简单问题并收到回复。
2. **划词**：回到主会话，在已完成回复中选中一句话，点击“更多详情”。检查网页用户消息包含默认指令、选文、所属消息、其他历史，并收到相关回答；主会话不应自动发送新消息。
3. **修改 prompt**：在“提示词”保存一段自定义要求，再划词，检查新请求采用保存值。需要回默认时点击“恢复默认”；原自定义值会被替换。
4. **新建与历史**：顶部“新建”应显示空白页；“历史”能重开刚才的讨论且不重复发送。追问一个依赖上文的问题，确认网页继续同一讨论。
5. **回主会话**：先在主输入框留一段草稿。网页回答结束后确认目标标题，点击“添加到 DSH”，检查原草稿保留并增加引用卡。添加时不应自动发送主会话。
6. **按需读**：补充“请用 read_webchat_reference 读取这份引用，再结合正文回答”并发送，检查真实工具结果。点击已发送引用卡应重开原网页。
7. **快照独立**：在网页继续追问后，旧的已发送引用应保留原内容；再次添加可以形成新快照。未发送的同一引用允许更新。
8. **完整重启**：调整尺寸，在官网设置简体中文，确认登录已记住。退出整个 DSH 再打开，检查小窗尺寸、语言、历史重开、已发送引用的按需读取；同一网页继续追问应能接续。
9. **菜单语言**：切换 DSH 界面语言并再次划词，三个选项应一致切换。官网语言是独立设置，不必跟随它变化。

## 当前边界

- Windows、Linux、普通浏览器宿主没有实机验收；本项目不以其它插件的跨平台支持代替自己的验证。
- 快照只覆盖已渲染分支；未加载早期历史、图片附件不算完整备份。未实现全量官网历史同步、档案导入导出。
- 大体量裁剪由回归覆盖，没有验证官网最大输入量。换屏及更小视口、主动退出官网后重登没有追加实机验证。
- 官网曾出现“使用环境异常”或服务繁忙提示，关闭非登录提示或服务恢复后可继续；没有修改或绕过认证流程。网站结构、服务状态变化可能影响网页适配。
